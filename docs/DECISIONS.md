# НЕ ТУДА — зафиксированные решения

- Онлайн-PWA, ориентированное на iPhone, также современные браузеры Android и ПК. Фактическая совместимость зависит от браузера и устройства; версии iOS и моделей, не проверенные на устройстве, не считаются подтверждёнными.
- Проект с нуля; Git и публичный деплой только после подтверждения владельца. Бюджет проекта — 0 ₽, без платного LLM и секретов в клиенте.
- Старт: геопозиция или ручной выбор. По умолчанию кольцо; желаемая длина с допуском, количество людей и общий бюджет задаются пользователем. Остановки по 15 минут учитываются в оценке времени, когда они действительно включены в маршрут.
- Омск; пользователь предпочитает тихие жилые кварталы, меланхоличную атмосферу; помощник — Умнай. Мат только при отдельном включении. Музыка — ссылки поиска Яндекс Музыки.
- Не выдавать непроверенные факты за данные: покрытие, освещение, часы работы, цены и открытость неизвестны, пока нет источника. Предпочтение тёмной эстетики не является оценкой безопасности. Исключаются намеренное проникновение в закрытые и аварийные объекты, стройки и на пути. Реальные карты могут быть неполны; пользователь должен проверять обстановку на месте.
- iOS PWA не обещает непрерывную работу GPS и звука при заблокированном экране; удержание экрана доступно только по возможностям браузера. Онлайн-провайдеры не обеспечивают гарантии доступности и могут ограничивать запросы.
- История и настройки сохраняются локально на устройстве; автоматической синхронизации между устройствами нет. Сброс данных браузера удалит локальную историю.
