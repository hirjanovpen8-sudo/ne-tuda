# НЕ ТУДА

Прототип веб-приложения для пеших прогулок по Омску: выберите старт на карте или через геолокацию, задайте желаемую длину и попробуйте построить кольцевой маршрут. Карта и маршрутизация используют внешние онлайн-сервисы. Это не средство обеспечения безопасности и не замена вниманию к окружающей обстановке.

## Установка и запуск

Нужны Node.js и npm; зависимости зафиксированы в `package-lock.json`. Из корня проекта:

```sh
npm ci
npm run dev
npm run build
npm test
```

`dev` запускает Vite на `127.0.0.1` (адрес и порт выводятся в терминале); `build` сначала проверяет TypeScript, затем собирает приложение в `dist`; `test` запускает Vitest однократно. Отдельно доступны `npm run typecheck` и `npm run preview` для проверки типов и локального просмотра сборки. Версия Node.js в проекте явно не закреплена; используйте версию, совместимую с установленными зависимостями.

### Windows: временная папка

Если сборка или тесты завершаются ошибкой доступа к системной временной папке, можно попробовать временно направить `TEMP` и `TMP` в папку проекта. В PowerShell из корня проекта:

```powershell
New-Item -ItemType Directory -Force .tmp | Out-Null
$env:TEMP = (Resolve-Path .tmp).Path
$env:TMP = $env:TEMP
npm run build
npm test
```

Переменные действуют только в текущем окне PowerShell. Это обходной вариант для проблем с временной папкой, а не универсальное исправление ошибок доступа.

## Установка как PWA

В production-сборке настроены манифест и service worker для кэширования файлов приложения. Для установки и геолокации обычно нужен защищённый контекст HTTPS; `localhost` подходит для локальной разработки. Доступность установки и названия пунктов зависят от браузера и версии ОС.

- **iOS:** откройте опубликованный HTTPS-адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте HTTPS-адрес в поддерживающем браузере, например Chrome → меню → «Установить приложение» или «Добавить на главный экран».

Адрес `127.0.0.1`, на котором по умолчанию слушает dev-сервер, доступен только на той же машине; это не адрес для установки с другого телефона. Реальная совместимость на конкретных устройствах и версиях ОС не подтверждена. Кэш оболочки не означает полноценную офлайн-карту или офлайн-построение маршрутов: для внешних данных требуется сеть и доступность сервисов.

## Текущее состояние и ограничения

- Старт выбирается на карте или по GPS. Поддерживаются только кольца со стартом в ограниченной области планировщика в Омске; это не официальная граница города. Желаемая длина — 1 000–30 000 м; найденная длина может отличаться до 30%, а подходящий маршрут может не найтись.
- Участники и бюджет пока не влияют на маршрут. Подбор остановок и проверка ограничений не реализованы: для построения необходимо указать 0 остановок и снять ограничения. Темп и атмосфера в текущем интерфейсе не предлагаются.
- Навигация показывает примерный прогресс и, если сервис вернул подходящие шаги, подсказки; голос зависит от поддержки браузером. Возможное отклонение определяется приблизительно, автоматического перестроения нет. GPS может ошибаться, особенно на пересечениях и рядом с началом и концом кольца.
- **Безопасность маршрута, проходимость, освещение и актуальность карты не гарантируются.** Соблюдайте знаки и правила, проверяйте обстановку на месте; не полагайтесь на приложение в опасной ситуации.
- Непрерывная работа GPS, голоса и приложения в фоне или при блокировке экрана не гарантируется, в частности на iOS. Сетевые сервисы могут быть недоступны или ограничивать запросы.

## Данные и приватность

Настройки, тема и до десяти геометрий завершённых маршрутов хранятся в `localStorage` браузера на устройстве; автоматической синхронизации нет. Очистка данных сайта может удалить их, а при недоступном хранилище сохранение не гарантируется. При выборе GPS браузер запрашивает разрешение на геолокацию. При построении координаты маршрутных точек отправляются внешнему сервису маршрутизации; при загрузке карты браузер обращается к её провайдеру. Учитывайте политики этих сервисов и не считайте локальное хранение гарантией конфиденциальности или безопасности.

## Провайдеры и атрибуция

- Карта: [OpenFreeMap](https://openfreemap.org/), стиль Dark; данные и картография [OpenMapTiles](https://openmaptiles.org/) и [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Сохраняйте видимую атрибуцию карты и соблюдайте применимые условия, включая ODbL.
- Пеший маршрут: публичный `routing.openstreetmap.de/routed-foot`. `driving` в URL — имя профиля протокола OSRM; используется отдельный пеший сервер. Его доступность и условия использования следует проверить перед развёртыванием; автомобильной или прямолинейной подмены нет.
- По кнопке «Найти места» приложение отправляет координаты старта в [Overpass](https://overpass-api.de/). Сервис может не отвечать; результаты — сырые данные OpenStreetMap, а не проверенные места или остановки маршрута. Адаптер [Nominatim](https://nominatim.openstreetmap.org/) пока не подключён к интерфейсу. Публичный Nominatim требует соблюдения [политики использования](https://operations.osmfoundation.org/policies/nominatim/), включая общий лимит запросов; адаптер сам не обеспечивает его для всех клиентов. Данные объектов и часы работы не проверены на актуальность.

Подробнее о проверках, ограничениях и ответственности интегратора — в [документации провайдеров](docs/PROVIDERS.md). Внешние сервисы могут менять правила и доступность; приведённые там результаты — разовый снимок, а не SLA.
